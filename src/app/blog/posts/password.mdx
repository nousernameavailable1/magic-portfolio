## Add protected pages

To protect a page or section, add its path to `pageAccessRoutes` in `src/lib/page-access-routes.ts`. A protected prefix also covers its nested pages.

The server-side proxy verifies the signed access cookie before it renders a protected page. `RouteGuard` still handles disabled routes in the navigation tree.

<CodeBlock
    marginBottom="16"
    highlight="2"
    codes={[
  {
    code:
`export const pageAccessRoutes = [
  "/about",
  "/projects",
  "/projects/once-ui",
] as const;`,
    language: "tsx",
    label: "src/lib/page-access-routes.ts"
  }
]} />

The code above ensures that `/projects/once-ui` is only accessible after providing the site password.

## Set a password

Set `PAGE_ACCESS_PASSWORD` in `.env.local` for local development. On the Docker host, set it in the untracked `.env` file used by Docker Compose.
